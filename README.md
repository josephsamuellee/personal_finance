# Personal Finance

Household finance for one shared home. Ruby 4.0.5, Rails 7.2.3, SQLite.

## Boot

```sh
bin/rails db:prepare
bin/rails server
```

The server listens on port 8090 at `http://serverlite:8090` when that hostname resolves to this machine. Set `PORT` to override the port.

## Test

```sh
bin/rails test
```
